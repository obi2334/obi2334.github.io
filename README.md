# Emmanuel Obi Developer Portfolio

Responsive portfolio inspired by the user-provided reference video. It features a floating navigation pill, profile hero, and project showcases using supplied screenshots from NaijaBet and Verified Exam. The email entered in the exam screenshot has been hidden for privacy.

## Preview
Open `index.html` in a browser. Keep the CSS, JavaScript, profile image, project screenshots, and CV PDF beside it.

## Publish
Upload all files in this folder to GitHub Pages, Vercel, or Netlify. Replace the screenshots with updated captures when the projects change.
